# Screenshots

Images referenced by the main `README.md`. The filenames it expects are `studio.png`,
`modulation.png`, `lyrics.png` and `export.png`.

Once these exist, uncomment the two image blocks in `README.md` (the hero image near the top and
the table in the Screenshots section).

Keep them at a sensible width, somewhere around 1600px. Full 4K screenshots make the page slow to
load and GitHub scales them down anyway.
